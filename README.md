# 🤖 Virtual Assistant in C++ with eSpeak (Text-to-Speech)

## 📌 Overview

This is a simple **Virtual Assistant built in C++** that performs basic system tasks like opening applications, telling the time, and greeting users. It also uses the **eSpeak API** to **speak responses aloud**, making the interaction more dynamic and user-friendly.

---

## 🧰 Technologies Used

- **C++**
- **eSpeak API** (Text-to-Speech)
- **Windows System Commands** (via `system()`)

---

## 🗣️ Features

- Text-to-speech response using **eSpeak**
- Open apps like **Notepad**, **Chrome**, or other system tools
- Get the current **time**
- Handles basic conversation (greeting, farewell)
- Easy to expand with new commands

---

## 🖥️ How It Works

1. Takes user input from the terminal.
2. Matches it with predefined commands.
3. Executes the associated system command.
4. Speaks the output using the **eSpeak API**.
